```text

└── README.md
```

## Concepts Used

* Node.js
* JavaScript
* `console.log()`
* Running Node.js programs
* Terminal output

## How to Run

First, check if Node.js is installed:

```bash
node --version
```

To run the first program:

```bash
node app.js
```

Output:

```text
Hello, Node.js!
I am learning backend development
```

To run the introduction program:

```bash
node introduction.js
```

Output:

```text
Name: Sanika
Education: B.Tech
Current Learning: Node.js
Goal: Backend Developer
```
